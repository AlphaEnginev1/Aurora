# Aurora Governance

The repository is the canonical engineering record. Architecture changes require an ADR. Security, network and privilege changes require tests and explicit review. No secrets are committed. Failed verification blocks capability activation. Live/production execution is a separate authorization stage.

## Consolidation Freeze

The repository is currently under the Aurora Consolidation Gate. New functionality is frozen until the gate's exit conditions are satisfied. See `docs/CONSOLIDATION_GATE.md`.
